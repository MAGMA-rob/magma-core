# magma-core
Core package for MAGMA. It defines utils, base classes used by other MAGMA packages. It also defines communication protocol between different magma packages.

Its version correspond to the paper MAGMA-GEN (june version).

This package does nothing on its own but it's required by any magma applications. 

Installation, links and recommendation are provided here: [core installation](https://magma-rob.github.io/docs/installation)
